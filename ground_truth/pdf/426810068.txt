Windows 2000 on Docker
A Docker image for Windows 2000 Advanced Server with SP4.
Start an instance
The instance can be accessed from:
RDP ( ), user , password .
VNC ( ), without password.
noVNC ( ), http://127.0.0.1:6080/vnc.html
Additionally the contents of the directory in the container will be exposed on the drive via SMB.
Environment variables
Number of cores the VM is permitted to use ( by default).
Amount of memory the VM is permitted to use ( by default).
VM keyboard layout ( by default).
Start QEMU in KVM mode ( by default).
The option is required for this variable to take effect.
