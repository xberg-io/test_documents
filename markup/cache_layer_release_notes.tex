\section{Cache Layer 4.2 Release
Notes}\label{cache-layer-4.2-release-notes}

Version 4.2 focuses on eviction correctness and observability. This
release is \textbf{backward compatible} with 4.1 configuration files,
but the default eviction policy has changed --- read the migration note
below.

\subsection{Highlights}\label{highlights}

\begin{itemize}
\tightlist
\item
  Adaptive replacement replaces plain LRU as the default policy.
\item
  Per-key TTLs are now honored to millisecond precision.
\item
  A new \texttt{cache.stats()} call exposes hit rate without a debug
  build.
\end{itemize}

\subsection{Behavior Changes}\label{behavior-changes}

The eviction default moved from \texttt{lru} to \texttt{arc}. ARC keeps
both a recency and a frequency list, so a single large scan no longer
flushes hot keys. To keep the old behavior, set
\texttt{policy\ =\ "lru"} explicitly.

\subsection{Metrics}\label{metrics}

The following counters are emitted on every flush interval:

{\def\LTcaptype{none} % do not increment counter
\begin{longtable}[]{@{}lll@{}}
\toprule\noalign{}
Metric & Type & Meaning \\
\midrule\noalign{}
\endhead
\bottomrule\noalign{}
\endlastfoot
\texttt{cache\_hits} & counter & Lookups served from memory \\
\texttt{cache\_misses} & counter & Lookups that fell through \\
\texttt{evicted\_entries} & counter & Keys removed under pressure \\
\texttt{resident\_bytes} & gauge & Current heap held by the cache \\
\end{longtable}
}

\subsection{Migration}\label{migration}

Upgrading is a \emph{drop-in} replacement for most users:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Bump the dependency to \texttt{4.2} and rebuild.
\item
  If you relied on strict LRU ordering, pin \texttt{policy\ =\ "lru"}.
\item
  Delete any custom \texttt{warmup\_hook} --- warmup is now automatic.
\end{enumerate}

Call \texttt{cache.compact()} once after startup to reclaim fragmented
slabs left by the previous version.
